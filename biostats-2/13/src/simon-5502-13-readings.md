## File details

This readings list was written by Steve Simon on 2026-05-14 and is placed in the public domain.

-   Jolliffe IT, Cadima J. Principal component analysis: a review and recent developments. Philos Trans A Math Phys Eng Sci. 2016 Apr 13;374(2065):20150202. doi: [10.1098/rsta.2015.0202][ref-jolliffe-2016].
    -   This is a very mathematical explanation that is heavy on formulas, but it does have some practical applications.
    
Columbia University Irving Medical Center. Principal Components Analysis. Available in [html format][ref-columbia-nodate1]
    -   A very brief, but still informative explanation followed by a large number of additional resources.
    
Columbia University Irving Medical Center. Principal Components Analysis or Exploratory Factor Analysis. Available in [html format][ref-columbia-nodate2]
    -   I like exploratory factor analysis better than principal components analysis, but this page tries to explain what each one does and when you would prefer one over another. It also includes some very nice resources.
